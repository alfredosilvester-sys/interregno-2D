# Interregno — Echi dell'Oro (2D Pixel Art)
Un piccolo prototipo giocabile per browser mobile, ispirato al genere soulslike. È un progetto originale: non contiene asset ufficiali di Elden Ring.

## Pubblicare su GitHub Pages
Carica `index.html`, `manifest.webmanifest`, `service-worker.js` e `icons/` nella radice del repository. In GitHub apri Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save. Dopo la pubblicazione apri il sito con Safari e scegli Condividi → Aggiungi alla schermata Home.

## Comandi
Touch: ◀ ▶ movimento, ⚔ attacco, ↗ schivata, ↑ salto, ✚ cura, ✦ interazione.
Tastiera: A/D o frecce, J attacca, K schiva, Spazio salta, H cura, E interagisci.

Include esplorazione a scorrimento, nemici, boss, rune, fiale di cura, luoghi di grazia, checkpoint e salvataggio locale. Prototipo iniziale, da testare su dispositivo.
